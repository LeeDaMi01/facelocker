# FaceLocker Application
얼굴인식 사물함을 관리하고 이용할 수 있는 애플리케이션입니다.

## 🔍 기능 소개
1. 로그인
2. 블루투스 연결
3. 사물함 남은 자리 확인
4. 개폐 로그 확인
5. 개폐시 앱 푸시 알림
6. 회원탈퇴

## 💡 기술 스택
+ Andfroid Studio
+ MySQL
